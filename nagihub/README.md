# Поликлиника для GitHub Pages

Это статическая версия проекта для публикации на GitHub Pages. GitHub Pages не выполняет PHP и не предоставляет MySQL, поэтому копия использует JavaScript и `localStorage` браузера вместо PHP-сессий и базы данных.

## Публикация

1. Создайте репозиторий на GitHub.
2. Загрузите содержимое этой папки в репозиторий.
3. В настройках репозитория откройте **Pages**.
4. Выберите источник **Deploy from a branch**, ветку `main` и каталог `/root`.
5. Откройте выданный GitHub Pages URL.

## Демо-доступ

- `admin` / `admin123`
- `registrar` / `registrar123`

Данные сохраняются только в браузере пользователя. Для сброса демонстрационных данных очистите `localStorage` сайта.
